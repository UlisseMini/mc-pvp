# Learning from same-state counterfactual actions

The development scout had seven actual grounded takeoffs within 150 ms of an incoming fresh hit in eight games for the first edge PPO. Suppressing only the first eligible takeoff changed two terminal wins into losses. The frozen target withheld its opening click gate near the opponent. These findings motivate a general improvement method. Use the same controls and 20 CPS limit.

If the first-stage selected development merit is below 85%, train four independent students from the first-stage PPO method winner. Each decision example starts from a snapshot of both players, all packet and input queues, and the simulator clock. Try alternative forward/sprint, sideways, click or Space commands for 1, 3 or 6 own input heads, then return to the unchanged controller. After identical continuation compare actual whole-fight win/draw/loss; no position reward or future information is fed to the released player. Learn only on a channel whose alternatives lead to different terminal outcomes. Sample near the opening, local incoming hurt, and throughout the bout. Each fit uses 768 updates of 48 snapshots on the original training split; validate every 32 updates on the eight development clocks. Select one winner on the same 18 exposed development clocks. Record raw branch counts and number of decisions whose terminal result changed. Publish the winner.

Test the frozen winner on a fresh 16-block native panel. Each block plays six cells (both seats times 31/109, 109/31 and 80/80 ms) against the unchanged target, one student bout per cell. Also play the parent and plain W-tap in each block at one rotating cell apiece, rotating together. Record all 96 student bouts, 16 parent bouts and 16 W-tap bouts. Use an independent prospective simulation panel from those 16 W-tap bouts. Use the identical earlier dominance threshold, block intervals and controls. Keep this study separate from the previous baskets. Select the release using development only.
