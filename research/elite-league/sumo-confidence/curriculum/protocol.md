# Carry a learned seven-CPS response back to twenty

The first 7-trained specialist won 32 of 32 live games at 7 but scored 8–24 at 20 on the same eight simulator clocks. The original 20-trained specialist scored 26–5–1 on the same 20-CPS clocks. These exposed pilot clocks are now development evidence for this follow-up. Use no logs from the main native evaluation to select a policy.

Start from each of the two independently released 7-CPS PPO checkpoints (the 32–0 first policy and the later overall development winner). Use seeds 2707 and 5081 per checkpoint and two matched learning schedules. The direct schedule always trains against the target with both caps at 20. The curriculum raises both caps from 7 to 20 in steps, then finishes with 768 full-cap updates. Both start with the same weights and use the same scenarios, RTTs and action exploration seeds. Across the first 768 updates use 7, 9, 11, 13, 15, 17, 19 and 20 in 96-update stages. Train each arm for 1,536 x 32 bouts. Select checkpoints on the original eight development clocks at 20 CPS. Select a winner per method on the original 18 exposed development clocks at 20 and compare with the earlier 20-CPS PPO specialist and normal W-tap on exactly that evaluation. Publish both winners even if they do not supersede the prior specialist.

Allocate a new native challenger test if the higher method exceeds the old 20 specialist's same-panel merit by 0.025 and has at least 0.70 mean points in both seats. Use 16 blocks: both seats and both asymmetric links, plus one rotating equal-80 seat, for five 20/20 games per block against the frozen champion; also play plain W-tap and the previous specialist once per block at a rotating asymmetric cell. Use prospective clock donors from these 16 W-tap control games for the same simulator comparison. A specialist title does not replace the general field title.
